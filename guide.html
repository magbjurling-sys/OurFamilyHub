Part 1 · continued

Add routines and tasks

This is where the day takes shape. Our advice: start from the default setup and adjust — don\'t build from scratch.

📋

Categories and routines

Settings → Profiles and categories
  • ★ Categories are just labels for where a star came from
  • ★ Edit steps any time; nothing is lost
  • ★ Kids complete them in StarTap; you approve the star
✅

Tasks

Admin → Manage tasks

Single actions under a category. Choose a type and, if you like, limit it to specific weekdays.

  • ★ Weekday limits, e.g. "Pack school bag" on weekdays only
🌙

What "resets overnight" means

At midnight, daily tasks and routine progress are cleared, so it\'s a clean slate every morning. Stars already earned stay on the board — only the to-do status resets.

Edit the steps of a routine in Admin — the child taps through these in StarTap.
